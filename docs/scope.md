# MVP Scope

## What this MVP does

- **Reflective conversation loop** — a Socratic conversational engine (situation → feeling → interpretation → fear → need → pattern → control → choice), depth-optional rather than a forced checklist, with a merged Comfort/Calm grounding mode.
- **Personal snippet archive** — one merged store for saved insights, self-compassion lines, and future-self letters, with resurfacing gated behind explicit user consent.
- **Weekly reflection ledger** — one simple log of validation-seeking vs. self-trust moments, shown as trend language ("a bit less than last week"), never raw scores.
- **Crisis-language detection** — a dedicated, non-negotiable safety layer that runs on every message and hardcodes an escalation response with real crisis resources.

## What this MVP explicitly does NOT include (yet)

These are real features on the roadmap, deliberately postponed until the MVP is validated with real users:

- Growth Constellations (visual pattern-linking)
- Recurring pattern detection / predictive check-ins
- External Wisdom Engine (RAG over self-growth literature) and Wisdom Pairing
- Emotionally Adaptive UI
- Formally staged AI Relationship Evolution
- Life-Building System

## Success criteria for this phase

The MVP is considered validated (and ready to expand) when a small group of real users has used it for a couple of weeks and:

- The reflective loop feels helpful rather than repetitive or interrogating.
- The archive gets used voluntarily.
- The ledger motivates rather than shames.
- No instance of real distress being misread as "just" a validation pattern.
